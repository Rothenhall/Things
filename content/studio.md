# The Things studio

The studio is where you build a character. It runs entirely in your browser.

## Tabs

- **Characters**: 9 presets to start from.
- **Body**: shape, ears, arms, feet, tail, muzzle, coloring and markings.
- **Fur**: pick a fabric, then adjust the pile sliders. Touching a slider switches the fabric to custom.
- **Face**: eyes, nose, mouth and cheeks.
- **Outfit**: hat, neckwear, glasses and decoration, including a bow.
- **Motion**: moods (idle, waving, talking, thinking, excited, sleepy), a boop and spin test, a mouth override and render quality.
- **Use it** (button next to Photo): export.
- **Guide**: in-app instructions for using and embedding characters.

## Controls

Drag the character to rotate it and click it to boop it. Undo and redo with Ctrl+Z and Ctrl+Shift+Z. The Surprise me button makes a random character. The Photo button saves a PNG.

## What can I export?

Save a PNG photo, save or open the character as a JSON file, or copy a code snippet for React, Next.js or plain HTML. The snippet contains only the settings you changed.
